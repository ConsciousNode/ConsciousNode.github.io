Xinu principle: do one thing well, then ask what else it can do within the same constraints.

Single-file software is a formal constraint the way a sonnet has fourteen lines. The constraint isn't a limitation — it's the shape that makes the work possible.

We work offline-first because presence shouldn't depend on connectivity. We work zero-dependency because a tool that needs the cloud isn't really yours. We work in the browser because the browser is the new bare metal.

The tools and the people making them are the same project.
